FLOW_DESIGN — 多端客户端关键流

范围：桌面（Electron）/移动（Capacitor）/Web 三宿主共享同一 app/dist SPA 与 src/native/bridge.ts 缝隙。

F1 启动流（桌面）

  1. Electron 主进程注册 app:// 特权 scheme → protocol.handle 映射 app/dist（SPA fallback → index.html）。
  2. BrowserWindow（contextIsolation+sandbox）载入 app://weave/index.html；preload 暴露 NativeBridge 与 WeaverNoteApp。
  3. SPA 启动：皮肤预引导（localStorage）→ Pinia/Vue → 路由守卫（无 token → /login）。
  4. API 基址：构建期 VITE_API_BASE（config.toml 注入）；Web 同源时为空串走相对路径。

F2 认证流

  1. 登录页 → axios POST {base}/api/auth/login → token 存 localStorage（移动端后续迁移 Capacitor Preferences）。
  2. 401 拦截 → 清凭据 → window.location.href='/login?expired=1'（三宿主统一，已从 /app/frontend/login 校正）。

F3 对话流（SSE）

fetch({base}/api/chat/stream)（Authorization: Bearer）→ 增量渲染（markdown/mermaid/katex/echarts）。断线重连走 /api/chat/stream/resume。媒体附件 /api/files/download?path=…&token=… 经 apiUrl() 绝对化。

F4 语音流（WS）

apiWsUrl('/api/voice/ws'|'/api/asr/ws/transcribe/stream')（wss + token 查询参数）→ AudioWorklet+rnnoise WASM 采集 → 二进制帧。宿主差异仅在权限提示（Electron 无感；移动需 usage string；Web 浏览器弹窗）。

F5 本地文件桥（桌面）

  1. SPA 调 NativeBridge.fs.pickDirectory() → ipcMain dialog.showOpenDialog → 返回绝对路径。
  2. fs.readTextFile / writeTextFile / listDir / reveal → 主进程校验绝对路径后执行。
  3. 下载：WeaverNoteApp.saveFile/downloadFile 兼容桥 → 主进程写系统下载目录（继承既有 useDownload 探测逻辑）。

F6 冒烟流（CI/交付闸门）

smoke_desktop.sh → electron --smoke → 挂载/桥读写列/截图断言 → SMOKE_RESULT JSON + 退出码。移动端未来等价物：模拟器启动 + 同页截图（W2/W3 规划）。

F7 云端 workspace 文件物化流（2026-09-29 波）

问题：附件按 workspace 相对路径渲染，但本地栈预览只读本地 workspace——云端上传（另一设备/Web 端）的文件本地缺失即 404。裁决：云端→本地单向物化，复用远端既有 /api/files/list + /api/files/download（生产 chatbot 后端同款，零服务端改动）；否决「sha256 索引表/blob 管道」（须上游部署，收益不匹配本波）与「服务端新增清单端点」（同上，留作后续优化）。

  1. 全量同步自动拉取（判据 1/1b/2）：首连 resync / 手动「重新全量同步」→ worker 递归远端清单（分页：/api/files/list offset/limit，limit≤1000，响应含 total/offset/truncated；单目录页数上限 32、无进展防御；旧服务端无 offset/total 字段时不翻页仅告警）→ 跳过内部目录/点文件（深度 8/目录 200/条目 5000 有界）→ 对 size < workspace_auto_max_mb(默认 10MB) 且（本地缺失 或 远端 mtime 更新）的文件流式下载（.part + 原子替换；mtime 对齐远端）→ 单周期上限 workspace_pull_cap(默认 200)，超出部分经 _workspace_pending 跨周期续拉至全量；崩溃残留 *.syncpart 按需清扫（>1h，每小时至多一次）。
  2. 大文件按需同步（判据 3）：预览打开时 GET /api/sync/workspace/status?path=——本地已有直接加载；缺失且远端存在且 ≤ 阈值 → 自动同步（“正在从云端同步…”）；> 阈值 → 显示「当前文件较大，是否同步？」+ 同步按钮 → POST /api/sync/workspace/fetch（上限 workspace_max_mb，默认 1024）→ 落盘后加载预览。
  3. 旧附件绝对路径归一化（2026-09-29 热修）：旧消息附件只有部署侧绝对路径（`rel_path:null`，`/…/user_workspaces/<账号段>/…`）——前端渲染/同步门控与后端 status/fetch 双层归一化为相对路径后再工作（无标记绝对路径原样保留=本地旧行为）。
  4. 冲突与安全（判据 4/5/6）：LWW（仅远端 mtime 显著更新才覆盖本地）；未绑定/远端缺失/不可达走既有 404/502 语义；rel_path 只接受 workspace 相对路径，落点 resolve 后必须在 workspace 内（..//绝对路径/符号链接逃逸拒绝）。
