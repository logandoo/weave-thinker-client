兼容桥（window.WeaverNoteApp）

继承 Android 壳历史契约：isDownloadSupported=true、saveFile/downloadFile/downloadFileWithProgress（异步落盘、同步返回 true）、onThemeChanged no-op。源 SPA 的 useDownload 自动启用原生路径。

远程 API 契约（客户端消费，源=chatbot backend）

  • REST: {api_base}/api/**（axios，Bearer）；SSE: /api/chat/stream[/resume]；WS: /api/voice/ws、/api/asr/ws/transcribe/stream；媒体: /api/files/download?path&token。
  • 后端侧待办（不在 chatbot 仓直接改）：CORS 放行客户端 origin（app://weave · capacitor://localhost · http://localhost）允许 Authorization 头与 credentials。

同步端点面（S1 波，2026-09-24；vendored server/ 新增 app/api/sync.py，前缀 /api/sync，JWT Bearer）

端点语义关键契约
POST /api/sync/devices设备注册（幂等按 id）body {id?, name, platform}；已存在同 id 设备→更新 last_seen_at 返回；revoked 设备 403
GET /api/sync/delta?cursor=C&limit=N&device_id=D增量事件流seq>cursor 分页（limit 默认 200，≤1000）；窗口内 Joplin 四规则压缩；device_id 抑制 origin 回显；返回 {events:[...], cursor:<最大seq>, has_more}
POST /api/sync/push批量提交本地变更body {device_id, events:[{entity_type, entity_id, op, payload, client_updated_at}]}；服务端 LWW 仲裁（incoming.updated_at>现有→应用；否则 skip）；天然幂等（同 payload 重复应用=同态）；per-event SAVEPOINT 部分失败不连坐；返回 {applied:[], skipped:[]}
PUT /api/sync/blobs/{sha256}内容寻址上传body=原始字节；服务端校验 sha256 实算一致（不符 400）；同 sha 幂等去重；上限 [sync] blob_max_mb
GET /api/sync/blobs/{sha256}下载存在→application/octet-stream；不存在 404
POST /api/sync/resync全量重建游标失效时导出该用户同步域全量当前态 {entities:{type:[rows]}, cursor:<当前最大seq>}（首批全量同步复用导出管线理念，Joplin resyncRequired 同款）

事件捕获=SQLAlchemy mapper 事件（app/services/sync_capture.py，after_insert/update/delete 同事务 connection.execute 写 sync_events + delete 时写 sync_tombstones）；域=conversations/messages/notes/notebooks/assistants。越权一律 404（沿用仓约定）。错误约定同 API.md 通用节。
